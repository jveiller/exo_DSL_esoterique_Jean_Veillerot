# Exercice programmer dans un langage ésotérique - Jean Veillerot

Le langage que j'ai choisi pour cet exercice est le langage Befunge. Sa page exolangs est disponible à cette URL : https://esolangs.org/wiki/Befunge.

L'interpréteur utilisé est celui-ci : https://github.com/amicloud/befunge93, un interpréteur en ligne est aussi disponible : https://amicloud.github.io/fungide/.

La commande pour lancer le programme est node exe.js p.bf entree1 entree2.

La commande pour lancer les tests est ./run.sh programme.bf
